# P3 테스트 먼저 개발 (TDD)

> 출처: [obra/superpowers](https://github.com/obra/superpowers) `test-driven-development` (commit `2ce8aa1`, MIT). 2조 P3 테스트 구조에 맞게 바꿨다.
> 우선순위: `CLAUDE.md` > `code-rules`(4장 테스트) > `p3-orders` > 이 파일.

## 철칙
**실패하는 테스트 없이 구현 코드를 쓰지 않는다.** 테스트가 실패하는 걸 보지 않았다면, 그 테스트가 맞는 걸 검사하는지 알 수 없다.
- 테스트보다 코드를 먼저 썼다면: 그 코드를 참고하지 말고 테스트부터 다시 시작한다.
- 예외(설정 파일, 자동 생성 코드, 버려질 실험 코드)는 사용자에게 먼저 묻는다.

## 빨강 → 초록 → 정리
1. **빨강**: 동작 하나만 검사하는 테스트를 쓴다. 이름은 동작을 말한다(`test_pay_twice_is_invalid_and_stock_decreases_once`).
2. **실패 확인 (필수)**: 실행해서 *예상한 이유로* 실패하는지 본다. 바로 통과하면 이미 있는 동작을 검사한 것 → 테스트를 고친다. import 오류로 실패하면 고치고 다시 본다.
3. **초록**: 테스트를 통과시키는 가장 작은 코드. 요청받지 않은 기능을 미리 넣지 않는다.
4. **통과 확인 (필수)**: 그 파일만이 아니라 `tests/orders` 전체를 다시 돌린다. 다른 테스트가 깨지면 지금 고친다.
5. **정리**: 초록 상태에서만 이름·중복을 정리한다. 동작은 바꾸지 않는다.

## P3에서 어떤 테스트를 어디에
| 계층 | 파일 예 | 무엇을 | DB |
|---|---|---|---|
| domain | `tests/orders/test_*_domain.py`, `test_order_status.py` | 상태 전이, 값 검증, 배송비·구매 제한 계산 | 없음 |
| application | `test_*_service.py` (+ `order_fakes.py`, `conftest.py`의 가짜 저장소) | 흐름 순서, 잠금 호출 순서, 실패 시 rollback 호출·값 원복 | 없음 |
| presentation | `test_*_router.py` | 상태 코드와 `{code,message}`: 정상·401·403·404·409·422 | 없음 |
| 실제 DB | `test_*_db.py` (`postgres_url` fixture) | 재고 전→후, rollback, 동시 결제·이중 결제·이중 취소 | 일회용 Docker |

- 실제 DB 테스트는 `P3_RUN_POSTGRES_TESTS=1`일 때만 돈다. 쓰고 버리는 컨테이너만 쓰고 개인 로컬 DB·공용 DB에는 접속하지 않는다.
- 주문·재고를 바꾸는 기능은 **rollback 테스트와 동시성 테스트가 필수**다(PR 템플릿 체크 항목).
- 가짜 저장소는 실제 트랜잭션처럼 commit 전 변경을 `pending`에 두고 rollback 시 버리게 만든다. 그래야 "일부만 저장됨"을 잡는다.

## 버그 고치기 예
1. 빨강: 버그를 재현하는 테스트(예: 같은 주문 동시 취소 시 재고가 두 번 늘어남) → 실패 확인
2. 초록: 원인 수정(주문 행 잠금) → 통과 확인
3. 회귀 확인: 수정을 잠깐 되돌려 테스트가 **다시 실패하는지** 보고 원상복구 (p3-verification)

## 이런 생각이 들면 멈춘다
- "너무 간단해서 테스트 필요 없다" / "나중에 테스트 쓰겠다" / "수동으로 Swagger에서 봤다"
- "테스트가 바로 통과했다" (실패를 본 적 없음)
- "이미 짠 코드가 아까워서 고쳐 쓰겠다"
→ 모두 테스트부터 다시 한다.

## 끝내기 전 확인
- [ ] 새 함수·분기마다 테스트가 있고, 각각 실패를 먼저 확인했다
- [ ] 실패 경로(403·404·409·422)와 rollback 테스트가 있다
- [ ] `tests/orders` 전체 + `P3_RUN_POSTGRES_TESTS=1` 실제 DB 테스트가 통과했다
- [ ] 테스트 출력에 경고·오류가 새로 생기지 않았다
