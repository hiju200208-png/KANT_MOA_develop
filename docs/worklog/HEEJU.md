- 회원가입·일반 로그인·내 정보 조회·로그아웃을 인증 4계층으로 구현했습니다. 비밀번호는 해시로 저장하고 JWT를 발급하며, 로그아웃한 토큰은 블랙리스트로 차단합니다.
- `get_current_user`와 `require_admin` 의존성을 준비했습니다. `CurrentUser.id`는 UUID이며 `role`은 `USER` 또는 `ADMIN`입니다. 관리자 계정 생성 CLI도 추가했습니다.
- Swagger에서 회원가입·로그인·내 정보 조회·로그아웃을 확인했습니다. 로그아웃한 토큰의 재사용은 401로 차단되며, 권한 테스트에서 미인증 401·일반 회원 403·관리자 200을 확인했습니다.
- 최신 `origin/main`을 병합해 P2 상품 모델과 P4 관리자 코드를 함께 확인할 수 있도록 했습니다.

### 로컬 DB와 마이그레이션

- Docker PostgreSQL은 로컬 `localhost:5433`으로 접속합니다. 공용 DB와 별도로 개발·실패 시나리오를 검증합니다.
- 마이그레이션 순서: `cd2b7db3c89b`(회원·블랙리스트) → `b49bcc205bbc`(나머지 공용 기준 테이블 16개) → `3f21520f9615`(회원 role TEXT·UUID 기본값 정렬).
- 로컬 적용 후 현재 버전과 head는 `3f21520f9615`입니다. 업무 테이블 18개와 `alembic_version`을 확인했습니다.
- Alembic에서 인증·상품 모델 7개를 수집하고, 모델에 없는 기존 테이블에 삭제안이 생성되지 않도록 비교 대상을 제한했습니다. 전체 18개 테이블의 ORM 수집이 완료된 상태는 아닙니다.
- 통합 테스트 수집 중 테스트용 환경변수가 실제 로컬 DB 설정을 덮는 문제를 확인했습니다. `P1_RUN_LOCAL_DB_TESTS=1`일 때만 로컬 주소를 검증한 뒤 설정을 불러오는 공통 테스트 설정을 추가했습니다.
